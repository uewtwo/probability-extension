# Privacy Policy / プライバシーポリシー — probability

**Last updated / 最終更新: 2026-05-31**

---

## English

**probability** ("the Extension") is designed with privacy as a core principle. All content analysis runs **entirely on your device** using Chrome's built-in AI (the Prompt API / Gemini Nano).

### Data we collect

**None.** The Extension does **not** collect, store on our servers, or transmit to us (or any third party) any personal information, browsing history, page content, images, or analysis results.

### How your data is processed

- **Page content (text, images, video frames)** is read from the page you are viewing only when an analysis runs, and is passed **only to the on-device AI model** built into your copy of Chrome. It is never sent to the developer or any external server.
- **Analysis results** (scores, summaries) are held temporarily in the browser's session memory for the current tab and are discarded when the tab is closed.
- **Your settings** (threshold, toggles) are stored using `chrome.storage.sync`. This may be synchronized across your own devices by Chrome through your Google account, but is never accessible to the developer.

### Permissions

The Extension requests only the permissions required for its single purpose (detecting AI-generated content on the current page). See the listing for per-permission justifications. No remote code is loaded or executed.

### Third parties

The Extension uses **no** analytics, advertising, tracking, or third-party services.

### Changes

Any changes to this policy will be published at this URL with an updated date.

### Contact

Questions: open an issue at https://github.com/uewtwo/probability-extension/issues

## 日本語

**probability**（以下「本拡張」）は、プライバシーを最重要原則として設計されています。コンテンツの判定はすべて、Chrome の組み込み AI（Prompt API / Gemini Nano）を用いて **お使いの端末内で完結** します。

### 収集する情報

**ありません。** 本拡張は、個人情報・閲覧履歴・ページの内容・画像・判定結果のいずれについても、開発者のサーバーや第三者へ送信したり、収集・保管したりすることは **一切ありません**。

### データの処理方法

- **ページの内容（テキスト・画像・動画のフレーム）** は、判定を実行するときにのみ閲覧中のページから読み取られ、お使いの Chrome に内蔵された **端末内 AI モデルにのみ** 渡されます。開発者や外部サーバーへ送信されることはありません。
- **判定結果**（スコア・要約）は、対象タブのためにブラウザのセッションメモリ上で一時的に保持され、タブを閉じると破棄されます。
- **設定**（しきい値・各トグル）は `chrome.storage.sync` に保存されます。Google アカウントを通じて Chrome がご自身の端末間で同期する場合がありますが、開発者がアクセスすることはありません。

### 権限

本拡張は、その単一目的（現在のページの AI 生成度判定）に必要な権限のみを要求します。各権限の理由は掲載情報に記載しています。リモートコードの読み込み・実行は行いません。

### 第三者

本拡張は、解析ツール・広告・トラッキング・第三者サービスを **一切使用しません**。

### 変更

本ポリシーの変更は、本 URL にて更新日とともに公開します。

### お問い合わせ

ご質問は https://github.com/uewtwo/probability-extension/issues までお寄せください。
