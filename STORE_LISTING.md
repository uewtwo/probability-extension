## 1. アイテム名 / Name

```
probability — AI generated content detector
```

## 2. 概要(Summary, 132文字以内)

**English**
```
Estimate how likely page text, images, and video are AI-generated — fully on-device with Chrome's built-in AI.
```

**日本語**
```
ページのテキスト・画像・動画が AI 生成である度合いを、Chrome 組み込み AI で端末内判定。データは外部送信なし。
```

## 3. 詳細説明 / Detailed description

**English**
```
probability tells you how likely the content on a web page was generated by AI.

It analyzes the page's text for AI-writing patterns and, separately, judges whether images and videos look like generative-AI output — giving each a 0–100% score with a short explanation. When a score crosses your threshold, you get a desktop notification and/or a pop-up window.

• On-device & private — All analysis runs locally using Chrome's built-in AI (Prompt API / Gemini Nano). Your page content and images are never sent to any server.
• Text detection — Scores the main article text and explains why.
• Image & video detection — Pre-collects media on the page; click the toolbar icon to judge each item separately.
• Configurable alerts — Adjustable threshold, desktop notifications, and/or an auto-opening pop-up window.
• Simple, modern UI — Clean design with automatic dark mode, available in English and Japanese.

Requirements: Chrome 138+ with built-in AI support. The on-device model is downloaded once from the extension's settings, and hardware requirements apply.

Note: Results are estimates based on writing style and visual cues. They are not a definitive proof of AI authorship.
```

**日本語**
```
probability は、Web ページ上のコンテンツがどれくらい AI によって生成されたものかを推定します。

本文のテキストを AI 特有の文体から判定し、さらに画像・動画が生成 AI っぽいかを別途判定。それぞれに 0〜100% のスコアと短い理由を表示します。スコアがしきい値を超えると、デスクトップ通知やポップアップウィンドウでお知らせします。

• 端末内処理でプライバシー保護 — すべての判定は Chrome 組み込み AI(Prompt API / Gemini Nano)でローカル実行。ページの内容や画像が外部サーバーへ送られることはありません。
• テキスト判定 — 本文を採点し、その根拠も提示。
• 画像・動画判定 — ページ内メディアを事前収集し、ツールバーアイコンのクリックで個別に判定。
• 通知方法を選べる — しきい値の調整、デスクトップ通知、ポップアップ自動表示に対応。
• シンプルでモダンな UI — ダークモード自動対応。英語・日本語に対応。

動作要件: 組み込み AI 対応の Chrome 138 以降。判定用モデルは設定画面から初回ダウンロードが必要で、ハードウェア要件があります。

注意: 判定結果は文体や見た目に基づく推定であり、AI 生成であることを確定するものではありません。
```

## 5. プライバシー（Privacy practices タブ）

### 単一用途の説明 / Single purpose

**English**
```
This extension has a single purpose: to estimate and display how likely the content (text, images, and video) on the web page the user is viewing was generated by AI, using Chrome's on-device built-in AI.
```

**日本語**
```
本拡張の単一目的は、ユーザーが閲覧している Web ページのコンテンツ(テキスト・画像・動画)が AI によって生成された度合いを、Chrome の端末内組み込み AI を用いて推定し表示することです。
```

### 権限の正当化 / Permission justifications

| 権限 | 正当化文（英語でそのまま入力可） |
| --- | --- |
| `host_permissions` (`<all_urls>`) | Required to read the text and fetch the images of whatever page the user chooses to analyze, since the user may run detection on any website. Content is only processed by the on-device AI model and never transmitted externally. |
| `scripting` / content script | Used to extract the main text and collect image/video elements from the active page so they can be analyzed. |
| `activeTab` | Used to access the content of the tab the user is currently acting on. |
| `tabs` | Used to associate analysis results and badge/score with the correct tab and to focus the relevant tab from a notification or pop-up. |
| `notifications` | Used to alert the user when a page's AI score exceeds their configured threshold. |
| `storage` | Used to save the user's settings (threshold, toggles) and to cache per-tab results in session memory. |
| Remote code | Not used. No remote/eval code is loaded; all logic ships inside the package. |
