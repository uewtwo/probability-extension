# probability

ページ内コンテンツが **AI 生成である度合い** を判定し、設定したしきい値以上のときに通知を出す Chrome 拡張です。判定には **Chrome 組み込み AI(Prompt API / Gemini Nano)** を使用し、すべての解析は端末上(ローカル)で実行されます。

> UI はブラウザの言語設定に追従します（既定は英語、日本語環境では日本語）。

## 特長

- **テキスト判定** — 本文の文体から AI 生成度(0〜100%)をゲージ + 理由で表示。
- **画像・動画判定** — ページ内のメディアを事前収集し、拡張アイコンをクリック(ポップアップ起動)するとテキストとは**別に**生成AIらしさを判定。マルチモーダル入力を使用。
- **オンデバイス** — Chrome 組み込み AI を利用。本文・画像は外部送信されません。
- **しきい値通知** — スコアがしきい値以上のときデスクトップ通知 + アイコンバッジ。
- **モデルダウンロード** — 設定画面から組み込み AI モデルを取得(進捗表示付き)。
- **多言語(英/日)** — `chrome.i18n` でブラウザ言語に連動。既定ロケールは英語。
- **ダークモード対応** — OS の配色設定に追従するシンプルでモダンな UI。

## 動作要件

- **Chrome 138 以降**(組み込み AI / Prompt API 対応版)。画像判定にはマルチモーダル対応が必要です。
- 組み込み AI のハードウェア要件(十分な空きストレージ・対応 GPU など)を満たすこと

## インストール（未パッケージ拡張として読み込み）

1. Chrome で `chrome://extensions` を開く
2. 右上の **デベロッパーモード** を ON
3. **パッケージ化されていない拡張機能を読み込む** をクリック
4. このフォルダ（`manifest.json` がある階層）を選択

## 使い方

1. ツールバーの probability アイコンをクリックしてポップアップを開く
   - **テキスト** タブ … 本文の AI 生成度
   - **画像・動画** タブ … メディアの生成AI判定（アイコンを開いた時点で自動開始）
2. 初回はモデルが未取得の場合があります。**設定 → AI モデル → モデルをダウンロード** で取得
3. スコアがしきい値以上になると通知が出ます

## 設定項目（オプション画面）

| 項目 | 説明 | 既定値 |
| --- | --- | --- |
| 通知のしきい値 | この%以上で「可能性が高い」と判定し通知 | 70% |
| ページ読み込み時にテキストを自動判定 | ページを開くたび本文を自動解析 | ON |
| 画像・動画を判定 | ポップアップ起動時にメディアを判定 | ON |
| デスクトップ通知 | しきい値超過時に通知 | ON |
| ツールバーにスコアバッジ | アイコンに数値表示 | ON |
| 解析する最小文字数 | これ未満のページはスキップ | 280 |

## 通知が表示されないとき

1. 設定画面の **通知 → テスト送信** でサンプル通知を発火できます。
2. 表示されない場合は **OS 側で Chrome の通知が許可されているか** を確認してください。
   - macOS: システム設定 → 通知 → Google Chrome を許可 / 集中モード(Focus)を解除
   - Windows: 設定 → システム → 通知 → Google Chrome を許可 / 集中モードを解除
3. それでも出ない場合は `chrome://settings/content/notifications` の設定を確認してください。

## ビルド / ストア用パッケージ

`manifest.json` をルートに置いた、Chrome ウェブストア入稿用 ZIP を `dist/` に生成します（JSON / JS の検証込み）。

```sh
make build          # または: npm run build / bash scripts/build.sh
make icons          # アイコン(icons/*.png)を再生成
make check          # JSON / JS の検証のみ
make clean          # dist/ と zip を削除
```

ストア掲載文・権限の正当化・プライバシー申告は [STORE_LISTING.md](STORE_LISTING.md)、プライバシーポリシーは [PRIVACY.md](PRIVACY.md) を参照。

## ファイル構成

```
manifest.json        拡張定義(MV3, default_locale = en)
background.js        service worker: テキスト/メディア判定・通知・バッジ
content.js           本文テキストとメディア(画像/動画)の抽出
popup.html/js/css    メイン UI(テキスト/メディアのタブ)
options.html/js/css  設定・モデルDL・通知テスト
lib/settings.js      共有の設定・分類ロジック
lib/detector.js      組み込み AI による判定(テキスト/画像)
lib/i18n.js          国際化ユーティリティ
_locales/en, _locales/ja  メッセージカタログ
theme.css            共有テーマ(ダーク/ライト)
icons/               アイコン(gen_icons.py で生成)
```

## 注意

判定結果はページ上の文体・見た目に基づく **推定** であり、AI 生成かどうかを確実に保証するものではありません。
